## 商品事实卡

在内部先建立以下底稿，不要默认完整展示给用户：

| 字段 | 内容 |
|---|---|
| 商品名称 / SKU | 明确到当前要讲的单品或规格 |
| 商品类别 | 服装、美妆、食品、3C、家居或其他 |
| 可见外观 | 图片中无歧义可见的颜色、结构、包装和配件 |
| 已确认参数 | 用户或官方资料提供的尺寸、材质、成分、功能、规格 |
| 目标人群 | 用户提供；未提供时只能作为策略假设，不写成产品承诺 |
| 使用场景 | 与已确认功能匹配的真实场景 |
| 价格权益 | 当前价格、优惠、赠品、渠道、起止时间 |
| 证明依据 | 商品演示、参数表、说明书、成分表、检测或授权资料 |
| 购买阻力 | 尺码、材质、耐用性、使用难度、适配性、售后等 |
| 待确认信息 | 缺少但会影响购买判断的信息 |
| 禁止表达 | 无依据的功效、销量、评价、库存、认证和比较 |

## 信息可信度分层

### A：可直接使用

- 用户明确提供并确认的事实；
- 官方商品页、说明书、参数表或品牌资料可核实的信息；
- 图片中清晰可见且不需要推断的特征。

### B：只能作为视觉描述

- 图片中看起来小巧、颜色柔和、包装有按压泵等可见状态。

不要把“看起来”升级成不可见性能，例如“轻便”不能自动变成具体重量，“金属质感”不能自动变成铝合金材质。

### C：需要确认

- OCR 不清晰的文字和数字；
- 用户只说“效果好”，但没说明效果及依据；
- 材质、成分、容量、续航、兼容范围、产地、认证、保质期；
- 价格、折扣、赠品、库存和活动有效期。

### D：禁止补造

- 虚假亲测、回购和第三方推荐；
- 销量、好评率、排名、获奖、专利和检测；
- 医疗、保健、减重、治疗或永久性效果；
- “全网最低”“最后一批”“马上恢复原价”等无实时依据的话术。
- 用户资料中没有的旧方案损坏和踩坑经历，例如被充电器刮伤、线材丢失、设备损坏。

## 卖点转换

使用 `F-B-S-E` 转换，不直接堆参数：

```text
Fact：已确认事实或功能
Benefit：对目标用户有什么具体好处
Scene：在哪个真实场景里有用
Evidence：通过什么参数、动作或画面证明
```

示例：

```text
Fact：用户提供“外套有双向拉链”
Benefit：坐下或骑车时下摆不容易顶住
Scene：通勤骑车、开车和室内坐下
Evidence：主播拉开下方拉链，展示坐姿和活动空间
```

每个核心卖点必须至少具备 Fact 和 Evidence。缺少 Evidence 时，降低表达强度或向用户补问。

如果删除 C/D 级信息后，没有任何能够支撑购买判断的 Fact + Evidence，不生成成品话术。优先询问成分/参数、合法功效、适用人群、真实使用反馈或可演示结构，最多一次 3 问。

## 风险表达检查

| 风险类型 | 不要直接写 | 改写方向 |
|---|---|---|
| 绝对化 | 最好、第一、顶级、百分百 | 说清具体参数、场景或体验边界 |
| 虚假稀缺 | 只剩最后几十件、马上没货 | 仅在用户提供实时库存和有效期时使用 |
| 虚假社会证明 | 人人都在买、朋友都问链接 | 删除；有真实评价时引用可核实原文和范围 |
| 虚构体验 | 我回购三次、我用了一个月 | 改成可观察演示；除非主播提供真实经历 |
| 功效承诺 | 治疗、根治、永久、立刻见效 | 使用合法、可证实的产品功能和体验描述 |
| 无依据比较 | 比某品牌强、全网最低 | 使用同一商品的真实使用前后或旧方案对比 |
| 数据认证 | 99% 有效、国家认证 | 仅使用可核实资料，并保留口径和来源 |
| 适配范围扩大 | 刚好放进通勤包、什么设备都能装 | 说准确尺寸和已验证装载示例，让用户核对自己的设备 |
| 虚构旧方案后果 | 鼠标被刮出印子、设备因此损坏 | 删除；只说当前真实整理需求和商品可见结构 |
| 结构利益绝对化 | 线材不会乱跑、放包里不占地 | 改成“帮助固定线材”“尺寸为…，请核对背包内袋” |

这是一套保守的语言风险检查，不等同于正式法律审查。用户要求法律合规结论或商品属于高监管类别时，优先检索当前官方法规与平台规则，并明确资料日期。

风险检查默认不写进主播台词。不要用“我不乱算”“我不能承诺”“我不说所有设备通用”等元话语表现合规；改成自然边界，例如：

- “具体能充几次会受手机型号和使用状态影响。”
- “目前确认适配这些型号，其他设备下单前看兼容表。”
- “敏感肌先看成分和使用说明，再决定是否适合。”

完整风险原因放到正文后的“待确认或禁说”，不让直播和短视频变成合规宣讲。

## 价格与活动

写价格、优惠、赠品、库存或活动时同时记录：

- 数值和单位；
- 适用 SKU；
- 适用平台或直播间；
- 起止时间；
- 是否需要券、满减、会员或组合购买；
- 库存信息的更新时间。

缺少任一会影响消费者判断的条件时，不写成确定权益。可以使用“以当前商品页显示为准”，但不能用这句话掩盖已经知道的关键限制。

## 输出前检查

- 台词里的每个数字能否回到用户资料或官方来源。
- 是否把图片视觉判断写成材质、功效或性能事实。
- 是否把策略假设写成商品承诺。
- 是否让形容词落到具体参数、场景或演示。
- 证明动作是否足以支撑数字和范围；“掂一下、看起来、应该能装”不能证明重量、尺寸或适配。
- 是否存在虚假第一人称经历或无来源的第三方评价。
- 是否保留价格权益的条件和有效期。
- 是否把精确活动时间模糊改成“到月底”，或遗漏适用渠道。
