# 豆包商业脚本

把商业需求整理成有明确受众、场景和产品证据的短视频脚本。

## 怎么用

提供 Brief、产品资料、受众和时长，说“根据这些资料写商业脚本”。

入口与完整规则：[SKILL.md](SKILL.md)。将整个仓库放入 AI 客户端的 Skills 目录，保持脚本和参考资料的相对路径。

## 在流程里的位置

先明确目标和证据，再写脚本；不能替品牌编造效果或案例。

## 运行条件

需要支持 Skill 的 AI 客户端，以及任务涉及的网页、文档读取或生成能力。此仓库不附带账号授权。

飞书、内容平台使用使用者自己的有效授权；写表、对外发送及其他需确认动作仍按 Skill 的门禁执行。仓库公开不等于飞书文档公开，也不代表共享维护者账号。

## 版本与更新

2026-09-10 对照本机当前业务规则整理。已经安装的 Git 工作副本可运行 `git pull --ff-only`；如有个人修改先备份或自行合并，不强制覆盖。

本仓库记录 Skill 规则与随包资源的版本；依赖的后台代码、数据源配置和登录状态需要分别维护。业务样本及外链保留原有归属，公开可见不代表获得二次商业使用授权。
